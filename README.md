# 7 leyendas de octubre

YouTube Short vertical, **2 minutos 45 segundos**, 1080×1920.

Tema elegido para octubre 2026: las leyendas mexicanas aguantan mejor un Short largo que un baile o un trend de audio, porque YouTube premia el gancho numerado y la historia oscura es el nicho que más retención sostiene cerca de los 3 minutos. El gancho abre un hueco (la número 1 no es La Llorona) y el cierre pide un comentario.

Son relatos populares, no un documental. La Isla de las Muñecas es un lugar real. El resto se cuenta como leyenda.
